# 🛡️ WinSecurity HelpDesk Tool

A lightweight, PowerShell-based security audit and management utility designed for **Help Desk Technicians** and **System Administrators**. This tool automates essential Windows security checks and configurations based on **CompTIA A+** principles.

---

## 🎯 Key Features

* **Privilege Check:** Verifies that the tool is running with Administrator rights.
* **BitLocker Audit:** Inspects drive encryption status, protection state, and volume status.
* **Firewall Management:** Checks operational states across all profiles (Domain, Private, Public).
* **Port Blocking Utility:** Quickly creates inbound firewall rules to block high-risk ports (e.g., RDP Port 3389).
* **Antivirus & Defender Check:** Verifies real-time protection and antivirus signature age.

# 🛡️ ابزار مدیریت و بازرسی امنیت ویندوز (WinSecurity HelpDesk)

یک ابزار کم‌حجم و مبتنی بر پاورشل برای بازرسی و مدیریت امنیت، طراحی‌شده برای **تکنسین‌های هلپ‌دسک** و **مدیران سیستم**. این ابزار بررسی‌ها و تنظیمات امنیتی ضروری ویندوز را بر اساس اصول **CompTIA A+** به صورت خودکار انجام می‌دهد.

---

## 🎯 ویژگی‌های کلیدی

* **بررسی سطح دسترسی:** تایید اینکه ابزار با دسترسی ادمین (Administrator) در حال اجراست.
* **بازرسی بیت‌لاکر (BitLocker):** بررسی وضعیت رمزنگاری درایوها، وضعیت محافظت و حالت ولوم‌ها.
* **مدیریت فایروال:** بررسی وضعیت عملیاتی فایروال در تمامی پروفایل‌ها (Domain, Private, Public).
* **ابزار مسدودسازی پورت:** ایجاد سریع قوانین فایروال ورودی برای مسدود کردن پورت‌های پرخطر (مانند پورت RDP شماره 3389).
* **بررسی آنتی‌ویروس و دیفندر:** تایید فعال بودن محافظت لحظه‌ای و سن امضای آنتی‌ویروس.
